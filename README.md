# Mail Export

批量保存邮件、简历及原始附件到本地。QQ 邮箱用只读 IMAP；凭据由实际运行环境的 QQ_EMAIL_ACCOUNT / QQ_EMAIL_AUTH_CODE 提供。Python 3.10+，下载及归档模块使用标准库。内容识别由宿主完成。

默认目录规则：只有简历直接放根目录；简历加其他随附材料才建子文件夹，同信材料一起保存，子文件夹与独立简历同层。文件夹和文件按用户各自要求命名，未要求时采用邮件主题和原始文件名。

## 安装

下载 [mail-export.zip](mail-export.zip) 并解压，按宿主支持的方式导入其中 mail-export 目录。更新安装与日常导出分开计时，不在每次导出前重新下载仓库。包只含运行所需的八个 skill 文件。

入口见 [SKILL.md](SKILL.md)，任务参数见 [QQ IMAP](references/qq-imap.md)，简历流程见 [简历流程](references/resume-workflow.md)。仓库 tests 为离线合成数据，运行 python -B -m unittest discover -s tests -v。
